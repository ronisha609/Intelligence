# Intelligence Analysis & Investigation Labs

This intelligence lab portfolio delivers **source-driven assessments** across insider risk, OSINT, protective intelligence, travel intelligence, threat-actor analysis, counterintelligence, and threat hunting.

Each lab transforms fragmented public information and technical evidence into defensible judgments, calibrated confidence, intelligence gaps, escalation triggers, and decisive operational support. The work fuses cybersecurity, digital forensics, and investigative analysis into rigorous intelligence tradecraft.

## Analytic Tradecraft Demonstrated

- Connect technical activity with identity, access, and behavior.
- Test competing explanations before reaching a judgment.
- Separate evidence, assumptions, and assessment.
- Identify collection gaps and define validation steps.
- Convert findings into prioritized actions and escalation decisions.

## Lab Standards

These are independent intelligence labs built for portfolio demonstration. Each lab separates verified facts, assumptions, analytical judgments, confidence, and collection gaps. Fictional scenarios are clearly labeled, while supporting evidence is grounded in reliable public sources. GitHub provides the lab overviews; full reports and source documentation are maintained in Notion.
